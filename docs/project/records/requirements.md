# 已确认需求与边界

来源是当前会话中用户多次纠偏后最后的选择，尤其“那就用这个，不用我刚刚说的那个，但是你只能改该插件，不能动其它插件”。先前“目标会话已在 B 窗则跨窗跳转”的提议被后续选择替代，不列为当前需求。

| 能力 | 当前要求 | 实现与验收状态 |
|---|---|---|
| 主窗口 | 默认一窗；从 BetterSidebar 主动新增空白第二窗 | 已安装；新增空白窗真实检查通过 |
| 数量 | 本次开放两个，后续允许扩展多个 | 当前只支持两个；更多窗口仍需布局与控制改动 |
| 左侧会话列表 | 一份；只操作选中的主窗 | 合成测试通过 |
| 独立状态 | 各窗会话、输入草稿、对话/思维图模式独立 | 活跃前端状态验证；重载后的独立草稿持久化未增加 |
| 焦点与布局 | 黑色整窗边框，左右并排，细分隔线可拖动 | 合成浏览器验证 |
| 右侧栏 | 最右侧展示选中窗的 BetterSidebar，普通贴纸可打开自己的编辑页 | 原贴纸打开函数配合合成服务验证；真实保存未验收 |
| 引用 | 原代码不改；各窗自己的引用、跳转与滚动 | 原跳转方法验证；完整创建/发送未验收 |
| UI 保留 | 已做好的 UI 不回滚 | 本分窗开发没有写入其他插件源码 |
| 范围 | 仅本插件；不能用跨会话代理修改其他插件 | 当前实现遵循 |

验收不能只看健康接口，也不能以合成侧栏或画布代替真实业务。对应 [[VER-isolated]]。


## 2026-09-19 共用侧栏外框修订

用户确认：两个展开按钮只有外层一组，不属于任何主窗；侧栏展开/收起及占用空间由外层维护。切换主窗只切换标签、选中页与内容状态，空内容使用 BetterSidebar 默认页；不会因另一窗旧的收起状态收起。主动收起后切窗也保持收起。本修订替代 .3 中各窗独立维护展开状态的行为。仅修改分窗插件；不替换其他插件业务代码或 store 工厂。

本修订已由 isolated.5 实现；按钮、切窗开关保持、内容保留和底栏真实检查通过。未建立会话时提供外层空白提示与主窗口管理；DSH 已提供草稿会话状态时直接展示 BetterSidebar 原默认页。主动点击贴纸入口仍允许展开侧栏，不能把“切窗保持收起”解释为禁止业务入口展开。
